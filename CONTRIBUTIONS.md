## 4. Reflection

See [REFLECTION.md](./REFLECTION.md) for the full reflection.

Contributing to peers' projects taught me that good documentation, clear issues, and timely communication are just as important as the code itself. The biggest challenge was managing timelines when owners were unavailable, which taught me to always contribute to multiple projects rather than relying on one merge. Working across different stacks (Java/Spring Boot and Python) in the same assignment also reinforced how transferable software engineering patterns are across languages.
